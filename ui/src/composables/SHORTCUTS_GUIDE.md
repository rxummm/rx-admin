## 💡 使用技巧

### 1. 输入框内的行为
- ✅ **Esc 键始终生效**：即使在输入框内也能关闭弹窗
- ❌ **其他快捷键被禁用**：避免与文本输入冲突（如 Ctrl+F 用于浏览器搜索）

### 2. 组合键顺序
- 先按住修饰键（Ctrl/Alt/Shift），再按功能键
- 例如：先按住 `Ctrl`，再按 `B`，然后同时释放

### 3. 视觉反馈
- 每次触发快捷键都会显示 Toast 提示
- 例如："侧边栏已切换"、"已切换到暗色主题"

### 4. 自定义扩展
开发者可以在组件中添加自定义快捷键：

```javascript
import { useKeyboardShortcuts } from '@/composables/useKeyboardShortcuts'

useKeyboardShortcuts([
  {
    key: 'Ctrl+S',
    handler: () => saveData(),
    description: '保存数据'
  }
])
```

## 🎬 使用场景示例

### 场景 1：快速切换主题
```
1. 正在浏览页面
2. 按下 Ctrl + D
3. 主题立即切换，显示提示消息
```

### 场景 2：折叠侧边栏获得更多空间
```
1. 查看表格数据时需要更宽视野
2. 按下 Ctrl + B
3. 侧边栏折叠，表格宽度自动扩展
```

### 场景 3：关闭误开的弹窗
```
1. 不小心打开了多个下拉菜单
2. 按下 Esc
3. 所有弹窗/菜单立即关闭
```

### 场景 4：刷新数据不刷新页面
```
1. 修改了数据后想查看最新状态
2. 按下 Ctrl + R
3. 仅重新请求数据，保持当前滚动位置
```

## 🔧 技术实现

### 核心文件
- **服务层**: [useKeyboardShortcuts.js](file://d:\vueprojects\RX\ui\src\composables\useKeyboardShortcuts.js)
- **UI 组件**: [ShortcutsHelp.vue](file://d:\vueprojects\RX\ui\src\components\ShortcutsHelp.vue)
- **集成点**: [layout/index.vue](file://d:\vueprojects\RX\ui\src\layout\index.vue)

### 工作原理
1. **全局监听**: 在 `document` 上监听 `keydown` 事件
2. **智能过滤**: 自动忽略输入框内的快捷键（除 Esc）
3. **防抖处理**: 防止快速按键导致重复触发
4. **错误捕获**: 快捷键执行失败不影响应用运行

### 性能优化
- ✅ 使用事件捕获阶段（`true` 参数）优先拦截
- ✅ 防抖延迟 100ms 避免重复触发
- ✅ 支持动态启用/禁用
- ✅ 组件卸载时自动清理

## 🐛 常见问题

### Q: 为什么在输入框内快捷键不生效？
A: 这是故意设计的，避免与文本编辑冲突。只有 Esc 键在输入框内有效。

### Q: 如何禁用某个快捷键？
A: 目前不支持单独禁用，但可以联系开发团队定制。

### Q: Mac 用户的 Cmd 键能用吗？
A: ✅ 可以！代码中已将 `Cmd` (metaKey) 映射为 `Ctrl`。

### Q: 快捷键冲突怎么办？
A: 系统会优先执行最先注册的快捷键。建议避免注册相同组合键。

### Q: 能否自定义快捷键？
A: 当前版本使用预设快捷键，未来版本将支持用户自定义。
